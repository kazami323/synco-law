## Что изменится для коллег в момент обновления

1. **Права.** Рядовой юрист теперь может подтверждать документ («Подтверждён
   юристом») и отправлять его в архив. Старший юрист может переводить в
   «Финальный». Это приведение к ТЗ, раздел 2 и 7.
2. **Маршрут согласования.** «Финальный» достижим напрямую из «Подтверждён
   юристом», без шага финансов. Раньше в организации без сотрудника с ролью
   «финансы» документ не доходил до конца вообще.
3. **Загруженные документы** приходят уже разобранными на пункты, и на них
   распространяется главное правило ТЗ: без прохода по всем пунктам статус не
   меняется. Документы, которые раньше согласовывались без этого шага, теперь
   потребуют прохода по пунктам.
4. **Новый экран** «Правовая проверка» у документа: пункты и нормы, логика,
   риски, комментарии, журнал действий.
5. **Тексты ошибок** стали русскими (было 63 английских).

Уже открытые документы в промежуточных статусах не трогаются: миграции только
добавляют две колонки (`review_runs.summary`, `clause_checks.clause_hash`),
данные не переписываются.
